# 🗳️ Decentralized Voting System

A blockchain-based decentralized voting system developed using Solidity and Ethereum blockchain technology.

## 📌 Project Overview

The Decentralized Voting System allows candidates to be registered and users to cast votes through a smart contract deployed on the Ethereum Sepolia Test Network.

The voting process is transparent, tamper-resistant, and verifiable because the voting data is stored on the blockchain.

## 🎯 Objectives

- Provide a decentralized voting mechanism.
- Prevent a user from voting multiple times.
- Store voting records securely on the blockchain.
- Provide transparent and verifiable voting.
- Reduce dependency on a centralized voting authority.

## ⛓️ Why Blockchain?

Blockchain is used because it provides:

- **Transparency** – Transactions can be publicly verified.
- **Immutability** – Confirmed blockchain records cannot easily be altered.
- **Security** – Smart contracts automatically enforce voting rules.
- **Decentralization** – Voting logic runs on the blockchain instead of a single centralized server.
- **Traceability** – Voting transactions can be tracked using their transaction hashes.
